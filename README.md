# Paper Workshop

Agent skills for academic writing — helping researchers write high-quality papers.

## Skills

- [code-to-method-blueprint](code-to-method-blueprint/) — turn research code into a detailed method blueprint for writing the Method section.
- [baseline-delta](baseline-delta/) — implement a method as a clean, tested delta (hooks/patches) on a pinned baseline submodule.

## Installation

```bash
git clone https://github.com/intcomp/paper-workshop.git
bash paper-workshop/install.sh
```

This installs all skills for Claude Code (`~/.claude/skills`) and Codex (`~/.agents/skills`). To update, `git pull` and rerun `install.sh`.
